# Native user-link command

`cupidbuild link-user --seed-manifest MANIFEST --root ROOT --source OBJECT --output OUTPUT`
links an existing `cat`, `hello` or `ls` object. The input is the output name plus
`.o`, and both leaves must resolve to the same existing physical directory below
`user/`. Repository and parent aliases may resolve inside that boundary. Linked
or nonregular leaves, escaping parents and unsupported object/output pairs fail.

The command delegates to the retained alias-aware link operation. That operation
keeps the physical parent chain, checked six-tool seed, object and candidate
through checked CupidLD execution, loader validation, CupidDis inspection and
atomic publication. Equal executable bytes preserve the existing timestamp.
The command creates no missing output directories.

Missing, duplicate, unknown and empty command options return usage status 2
before filesystem publication. Link failures return the operation's diagnostic
and preserve the guarded output. Help identifies `--source` as an object input.
