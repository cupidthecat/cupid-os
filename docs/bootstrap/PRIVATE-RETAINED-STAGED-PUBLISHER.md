Twenty native and Cupid-built cases pass across Windows and Linux. The private
caller runs checked CupidObj, retains its template, composes a complete 200 MiB
candidate, stages files through the existing FAT16 core and finishes guarded
publication. This extends the [retained publisher](PRIVATE-RETAINED-CHECKED-PUBLISHER.md)
with random reads and writes through its owned candidate store.

The adapter, header and three private includes keep their accepted bytes. Both
checked callers use the exact qualified disk renderer, FAT staging and Unicode

## Complete images and rejection

Twelve positive cases cover reuse, forced formatting and an absent previous
image. Each stages a 131,123-byte payload into `/BIN/ALPHA.BIN` and
`/DOCS/Straße.txt`, creates empty `/EMPTY.DAT`, then replaces `ALPHA.BIN` with
the first 513 payload bytes. Every complete image matches the independent Python
author by SHA-256 and 3,200 separate 64 KiB block comparisons.

A separate read-only FAT parser checks both FAT copies, exact short names,
complete file bytes and minimal cluster chains. The Unicode name becomes
`STRASSE.TXT`; the replacement uses one cluster, the full payload uses 33, and
the empty file uses none. Fresh and reused oracle preparation both succeed
within the existing directory-capacity rules.

Eight negative cases preserve every previous public byte, identity and
modification time. An injected second payload-read failure occurs after writes;
the poisoned FAT volume rejects retry without another write. A file used as a
directory also rejects. In both paths the caller leaves the candidate unfinished,
publication fails, and closing the transaction removes its private entries.

The actual producer retains its 60-second bound. Each complete caller retains
18,000 seconds; Linux retains 32 MiB and 10,240 descriptors. Nine conventional
producer commands are forbidden. Verified duplicate runtime images retire after
their complete comparisons. Canonical images stay local; review does not claim
a later reread of retired outputs or native temporary fixtures.
