## Interface and lifetime

The module exposes three operations:

- `cupidbuild_source_file_open_quota` takes a working root, a required file
  request, an entry quota and an owner output. Failure clears a supplied output.
- `cupidbuild_source_file_view` revalidates before returning the observer,
  physical parent, logical leaf, normalized absolute request and selected
  physical file spelling. Failure clears every supplied view field.
- `cupidbuild_source_file_close` closes the observer and releases owned names.
  Closing a null owner succeeds.

Both caller strings may be released after successful construction. The fixture
overwrites them before obtaining a view. Names and the observer belong to the
owner through close. A borrowing transaction must close first. Callers must
revalidate before and after consuming borrowed views.

Construction captures metadata. Retained streaming through the borrowed
observer adds payload custody and digest checks. Metadata alone cannot detect
a same-size edit whose timestamp is restored. The contracts retain that
distinction: metadata accepts the restored-time case, while streaming and
borrowed publication reject it and remain poisoned.

The physical file spelling joins the resolved parent with the original leaf
name. On Windows, Python may canonicalize the leaf's filename case separately.
The actual Python oracle checks `samefile` between both spellings; the owner
preserves the requested leaf case. Host file names and guest stage destinations
remain separate namespaces.

## Bounds and rejection behavior

The owner uses the existing 8,192-byte path storage and retained-entry quota.
The quota includes the physical root anchor, every absolute ancestor and the
file leaf. A two-entry quota cannot hold the deep fixture roots. Zero,
`SIZE_MAX`, insufficient quotas, invalid arguments, malformed UTF-8 and
overlong requests reject. Missing files, directory leaves, file parents, linked
leaves and special leaves reject; existing parent aliases remain admissible.
No source or output-name policy is weakened.

The file owner keeps the source observer's name profile. POSIX literal colon,
backslash, newline and tab names remain file bytes. Windows continues to use
its existing drive and UNC resolver and UTF-8 codec. The module adds no host
imports. It introduces no normal producer source or ownership change.
