# Retained optional disk stages

The private publisher in `C:/Users/admin/cw9` accepts optional repository stages
after required files. It validates every destination before running a producer,
observes each source through retained handles, freezes present payloads with
matching complete size and SHA-256, and keeps first-component absence facts
through final guarded publication. Missing stages neither write a guest file nor
replace an earlier destination. Present stages keep request order and the final
projected destination wins. Every earlier capture remains an input even after a
later stage replaces its guest file.

The capture owns its frozen spellings and destination bytes across input-table
growth. Repeated logical sources reuse a capture. Every explicitly registered
request still checks its payload against the observed source, including duplicate
requests. Kernel and identical required live paths reuse their existing captures;
the caller can explicitly register the boot input. The request has at most 4,096
stages and retains FAT16's unsigned 32-bit file bound. Image work uses bounded
range I/O rather than a complete-image allocation.
