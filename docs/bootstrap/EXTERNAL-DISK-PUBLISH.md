the accepted external stage API to the complete FAT16 publisher. It retains the
current hosted library and external host adapter while copying the required
publisher components from the earlier private source. Installed tools and normal

publisher borrows each observer explicitly selected by an external stage once.
Repeated requests with the same observer share that binding. Different observer
pointers for one physical root retain the host's repeated-root rejection.
External observers must already be open and remain alive through transaction
close. Stage capture still requires the exact primary observer and the borrowed
external authority before discovery, including absence.

repository stages. External stages keep their selected observer even when their
logical source matches a repository path. Explicit registered inputs retain the
complete observed size and digest check. Required and optional destinations keep
their existing order, validation and final replacement rules.
