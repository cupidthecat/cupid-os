an array size. The owner uses this for its copied strings. The compiler's three
regression methods pass on native and reconstructed checked tools on Windows
and Linux, including a freestanding runtime and useful invalid-source cases.

compiler, and eighteen native IR/object selectors pass. ADR 0479 records the

its new capability. Linux stage two passes across 45 objects and six tools in

the worker import profile's procedure order. CupidLD sorts import names; the
profile had appended CreateThread. All six fresh links match their preceding
image bytes, and a new real checked-assembler/linker test validates the exact
profile. ADR 0480 records the dependency order.

The eleven permanent owner methods pass with native and checked callers on
both hosts. They cover argument and option-owner lifetime, present/missing
inputs, external roots, constructor bounds, payload/metadata drift and
permanent rejection after a failed view. Linux keeps the 32 MiB address-space,
10,240-descriptor and sixty-second case bounds. Metadata fixtures separately
check every new SDK input and object pair; they do not establish a producer
or release authority by themselves.

Fresh original lifetime selections pass all 156 Windows and eighty Linux
calls. All twelve capacity cases pass with 4,096 staged files, covering native
and checked callers, flat and distinct-parent inputs, Windows drive/UNC roots
and Linux roots. Their sixty-second limits remain unchanged; checked Linux
also keeps 32 MiB and 10,240 descriptors. The slowest Windows UNC checked

The integrated host, path, file and stage objects match the previously

The framework selection passes 171 methods with one existing platform skip,

The full metadata selection passes 99 methods with three existing platform

replacement-tool consumers remain required before seed adoption. Their cold
normal OS builds and runtime checks must use the qualified replacement tools.
Stage-two success and the installed-seed image check do not satisfy those gates.

Image publication, full-width retained stores, the normal image CLI/Make
handoff and the three Python coordinators remain open. The normal graph still
has 449 CupidBuild transforms and three Python transforms. Installed seed files
and the read-only TempleOS scope remain unchanged.
