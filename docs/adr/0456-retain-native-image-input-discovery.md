## Decision

Give path selection an owner that resolves the original absolute spelling,
retains the physical parent before releasing the resolution handle, and rejects
linked or special file leaves. Optional missing suffixes retain their first
absence beneath the nearest existing directory. Revalidation checks ordinary
observations and the original parent binding. Ordinary UNC physical names use
the same existing Windows directory resolver without adding imports.

Give image input discovery a separate owner. Copy requested paths, canonical
paths, stage destinations and the image spelling. Retain the working root and
required manifest, bootloader and kernel paths. Reuse the primary observer for
its physical descendants; intern external roots by retained directory identity.
Repeated original paths reuse observations. Keep this owner alive until all
transactions borrowing its observers close.

Compare only already retained file entries when verifying a selected file's
identity. The comparison performs ordinary revalidation, observes no new leaf
and grants no source authority. Invalid comparisons clear the supplied result
and poison the supplied observers. Direct positive and negative contracts cover
same files, hardlinks, different files, unobserved entries, malformed paths,
null arguments, metadata drift and streamed digest drift.

Discovery does not grant release authority, freeze payloads, create output
parents or publish an image. Those responsibilities remain with the command
caller. Keep the new source outside the live normal producer closure until its
remaining SDK/public consumer checks close.
