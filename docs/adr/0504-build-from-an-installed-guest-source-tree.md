# Build from an installed guest source tree

The source-media worker reads the project at `/src`. An editable
checkout can live elsewhere, and moving it must preserve the logical
paths that CupidC uses for includes, diagnostics, and generated bytes.

A compile list can start with `root` and an absolute VFS directory.
CupidC resolves its source and include paths under that directory.
The same option on a kernel job locates the boot source, linker script,
and kernel symbol headers. A kernel job also runs from the editable
HomeFS plan. Jobs without a root line retain their existing defaults.

The installed-tree replay puts the project in `/home/project` and the
plan in `/home/cupidbuild.job`. CupidBuild reads and writes HomeFS
directly. The host checker still prepares that initial tree and plan.
