# ADR 0410: Carry exact long-path bootstrap profiles

Date: 2026-09-29

Status: Paired native proofs verified; seed promotion pending

The Windows long-file adapter needs one extra resolver shim and a distinct
ordinary-tool import table. Keep explicit profile selection in the paired
bootstrap and contract-publication drivers. Default capture retains 76 producer
inputs; the long profile captures 77 on both hosts. The installed release stays
pinned while the new profile is proved.

The v2 shared reader admits count 77 only with the exact Windows plan and the
complete installed parent pair. Linux shares its plan between both profiles,
so count and parent remain part of validation. A separate exact Windows image
profile requires the ordinary resolver import. Broad import allowances would
hide mixed generations during checked execution. Historical count, plan, parent
and import combinations remain independently validated. Python's installed seed
verifier remains pinned to the reviewed release until promotion.

Contract authoring and live verification check either complete producer
inventory, with the resolver present only in the long profile. Publication
captures 89 inputs in either mode; Make includes the resolver dependency.
Reuse requires the requested profile. Behavior fixtures bind actual captured
execution and plan parents. A long filename profile does not imply support for
a long child working directory or unrestricted filesystem aliases.

Both hosts pass 259 profile/publication methods. Checked readers agree on 1,281
manifest and pair cases and five shared object pairs. The complete native Windows
six-tool suite builds and exercises the new checked profile. The bootstrap log
retains evidence, failed fixture approaches and remaining work.

Seventeen bootstrap driver regressions pass on each host, and the graph mutation
corpus passes. Incremental Windows image acceptance uses the installed seeds,
83 freshly checked Doom objects and 156 objects with identical source-specific
closures. Sixteen artifacts, three user programs and the private four-CPU smoke
pass. This evidence preserves OS integration while the new profile awaits its
own paired staged proofs.

Both native staged proofs now pass at source revision `909d84ef`. Their complete

Independent checks validate the committed closure and all three stages. A

behavior fixture whose driver had replaced the exact profile's recorded parents.
